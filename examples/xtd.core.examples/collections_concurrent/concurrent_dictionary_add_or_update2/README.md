# concurrent_dictionary_add_or_update

Demonstrates how to use [xtd::collections::concurrent::concurrent_dictionary::add_or_update](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1concurrent_1_1concurrent__dictionary.html#aa2148d165dee5760987afa8d552e59c8) method.

## Sources

* [src/concurrent_dictionary_add_or_update.cpp](src/concurrent_dictionary_add_or_update.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```cmake
xtdc run
```
