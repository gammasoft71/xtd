# concurrent_dictionary

Demonstrates how to use [xtd::collections::concurrent::concurrent_dictionary](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1concurrent_1_1concurrent__dictionary.html) class.

## Sources

* [src/concurrent_dictionary.cpp](src/concurrent_dictionary.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```cmake
xtdc run
```

## Output

```
The square of 23 is 529 (should be 529)
```
