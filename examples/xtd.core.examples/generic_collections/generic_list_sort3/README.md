# generic_list_sort3

Shows how to use [xtd::collections::generic::list::sort](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1generic_1_1list.html#a9a22f137ea0a902320be43d8d494b1a8) method.

## Sources

* [src/generic_list_sort3.cpp](src/generic_list_sort3.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```cmake
xtdc run
```
