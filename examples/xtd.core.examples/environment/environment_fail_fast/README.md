# environment_fail_fast

Demonstrates how to use [xtd::environment::fail_fast](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1environment.html#a676d042ff30472e10924918da3d47aee) method.

## Sources

* [src/environment_fail_fast.cpp](src/environment_fail_fast.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```shell
xtdc run
```

## Output

```
Start application

Process terminated.
   at xtd::environment::fail_fast()
   at main
```
