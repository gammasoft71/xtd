# array examples

[This folder](.) contains guid examples used by [Reference Guide](https://gammasoft71.github.io/xtd/reference_guides/latest/) and more.

* [array](array/README.md) shows how to use how to use [xtd::array](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1array.html) class.
* [array_as_read_only](array_as_read_only/README.md) shows how to use [xtd::array::as_read_only](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1array_3_4.html#a7edca610710ffecef0f2f2fa1db6f2b3) method.
* [array_sort](array_sort/README.md) shows how to use [xtd:: array::sort](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1generic_1_1list.html#a20f55886f3702296928569b3e8e9d82b) method.
* [array_sort2](array_sort2/README.md) shows how to use [xtd:: array::sort](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1generic_1_1list.html#a163fddfd93594697d79cdda1588963b8) method.
* [array_sort3](array_sort3/README.md) shows how to use [xtd:: array::sort](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1generic_1_1list.html#a9a22f137ea0a902320be43d8d494b1a8) method.
* [array2](array2/README.md) shows how to use [xtd::array](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1array.html) class.
* [array3](array3/README.md) shows how to use [xtd::array](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1array.html) class.

## Build and run any project

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```shell
xtdc run -t any_project_name
```
