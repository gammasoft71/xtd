# collections specialized examples

[This folder](.) contains collections examples used by [Reference Guide](https://gammasoft71.github.io/xtd/reference_guides/latest/) and more.

* [specialized_ordered_dictionary](specialized_ordered_dictionary/README.md) demonstrates how to use [xtd::collections::specialized::ordered_dictionary](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1specialized_1_1ordered__dictionary.html) class.

## Build and run any project

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```shell
xtdc run -t any_project_name
```
