# extentions_enumerable_iterator

Demonstrates how to use [xtd::collections::generic::extensions::enumerable_iterator](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1collections_1_1generic_1_1extensions_1_1enumerable__iterators.html) class.

## Sources

* [src/extentions_enumerable_iterator.cpp](src/extentions_enumerable_iterator.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```cmake
xtdc run
```
