# parallel_for_async

Demonstrates how to use [xtd::threading::tasks:parallel::for_async](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1parallel.html#a17cc7e1f51a6d5fb9d1614686d1a893c) method.

## Sources

* [src/parallel_for_async.cpp](src/parallel_for_async.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```cmake
xtdc run
```
