# Tasks examples

[This folder](.) contains format examples used by [Reference Guide](https://codedocs.xyz/gammasoft71/xtd/) and more.

* [parallel_for_async](parallel_for_async/README.md) demonstrates how to use [xtd::threading::tasks:parallel::for_async](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1parallel.html#a17cc7e1f51a6d5fb9d1614686d1a893c) method.
* [tasks](tasks/README.md) demonstrates how to use [xtd::threading::tasks:task](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1task_3_01void_01_4.html) class.
* [task](task/README.md) demonstrates how to use [xtd::threading::tasks:task](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1task_3_01void_01_4.html) class.
* [task_completion_source](task_completion_source/README.md) demonstrates how to use [xtd::threading::tasks:task_completion_source](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1task_1_1completion_1_1source.html) class.
* [task_delay](task_delay/README.md) demonstrates how to use [xtd::threading::tasks:task::delay](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1task_3_01void_01_4.html) method.

## Build and run any project

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```shell
xtdc run -t any_project_name
```
