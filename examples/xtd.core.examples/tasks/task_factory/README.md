# task_factory

Demonstrates how to use [xtd::threading::tasks:task_factory](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1task__factory.html) class.

## Sources

* [src/task_factory.cpp](src/task_factory.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```cmake
xtdc run
```
