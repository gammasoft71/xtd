# Tasks examples

[This folder](.) contains xtd.forms other examples.

* [form_and_std_threads](form_and_std_threads/README.md) demonstrates how to threads (std::thread) can update ui with [xtd::forms::control::invoke](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1forms_1_1control.html#a17ec51282322d8387937dc8dad438e32) method.
* [form_and_task](form_and_task/README.md) demonstrates how to a task can update ui with [xtd::threading::tasks::task](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1tasks_1_1task_3_01void_01_4.html) class.
* [form_and_tasks](form_and_tasks/README.md) demonstrates how to tasks can update ui with [xtd::forms::control::invoke](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1forms_1_1control.html#a17ec51282322d8387937dc8dad438e32) method.
* [form_and_thread](form_and_thread/README.md) demonstrates how to a thread can update ui with [xtd::threading::thread](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1threading_1_1thread.html) class.
* [form_and_threads](form_and_threads/README.md) demonstrates how to threads can update ui with [xtd::forms::control::invoke](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1forms_1_1control.html#a17ec51282322d8387937dc8dad438e32) method.

## Build and run any project

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```shell
xtdc run -t any_project_name
```
