# hello_world_phylactery

The classic first application "Hello, World!" with [GDI+ drawing](https://gammasoft71.github.io/xtd/reference_guides/latest/group__xtd__drawing.html) objects.

## Sources

* [src/hello_world_phylactery.cpp](src/hello_world_phylactery.cpp)
* [CMakeLists.txt](CMakeLists.txt)

## Build and run

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```shell
xtdc run
```
