# Graphics examples

[This folder](.) contains colors examples.

* [graphics](graphics/README.md) demonstrates how to use [xtd::drawing::graphics](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1drawing_1_1graphics.html) class.
* [graphics_clear](graphics_clear/README.md) demonstrates how to use [xtd::drawing::graphics::clear](https://gammasoft71.github.io/xtd/reference_guides/latest/classxtd_1_1drawing_1_1graphics.html#a94085c1c7d76cd9c3d809cf4637d4367) method.

## Build and run any project

Open "Command Prompt" or "Terminal". Navigate to the folder that contains the project and type the following:

```shell
xtdc run -t any_project_name
```
