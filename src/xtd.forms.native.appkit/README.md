
# xtd.form.native.appkit

xtd.forms is made to have many toolkits: native toolkit like win32 api, appkit, ... or other third party libraries/framework toolkit like wxWidgets, qt5, ....

The toolkit [xtd.form.native.appkit](.) is based on Apple [AppKit](https://developer.apple.com/documentation/appkit/)  libraries.

## Remarks

This toolkit run only on macOS.
