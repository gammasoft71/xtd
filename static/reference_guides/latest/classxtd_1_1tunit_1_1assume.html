Definition

The assume class contains a collection of static methods that implement the most common assertions used in xtd::tUnit.

Namespace
xtd::tunit
Library
xtd.tunit
Remarks
Assumptions are intended to express the state a test must be in to provide a meaningful result. They are functionally similar to assertions, however a unmet assumption will produce an aborted test result, as opposed to a failure.
Examples
This example show how to used some methods :
#include <xtd/xtd.tunit>
#include <stdexcept>
using namespace xtd::tunit;
namespace unit_tests {
// The class test must be declared with test_class_ helper.
class test_class_(test) {
void test_method_(test_case1) {
assume::is_true(true);
}
void test_method_(test_case2) {
assume::is_false(true);
}
void test_method_(test_case3) {
assume::does_not_throw([] {throw std::range_error("error");});
}
};
}
auto main() -> int {
return console_unit_test().run();
}
